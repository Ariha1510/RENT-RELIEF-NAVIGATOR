# Rent Relief Navigator

A web application that helps users discover affordable rental homes based on their budget, preferred location, and essential amenities. It simplifies the house-hunting process by providing an intuitive search interface and relevant property information.

---

## Features

-  Search rental properties by location
-  Filter properties by budget
-  View property details
-  Location-based property discovery
-  Responsive user interface
-  Fast and modern frontend built with React & Vite

##  Installation

Clone the repository

```bash
git clone https://github.com/yourusername/rent-relief-navigator.git
```

Navigate into the project

```bash
cd rent-relief-navigator
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
